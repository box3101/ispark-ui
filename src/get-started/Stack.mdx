# 스택 · 패키지 · 명령어

## 패키지: 최소로 시작

미리 다 깔지 않는다. 필요해지면 그때 추가한다. Phase 1은 7개로 출발한다.

**Storybook**

- `@storybook/vue3-vite` · Storybook 본체 (Vue 3 + Vite 빌더)
- `@storybook/test` · `fn()`, `expect`, `userEvent`, `within`
- `@storybook/addon-essentials` · Controls, Docs, Viewport, Backgrounds

**테스트**

- `vitest` · 러너
- `@vitejs/plugin-vue` · Vue SFC 처리
- `@testing-library/vue` · `render`, `screen`
- `jsdom` · Node에서 DOM 에뮬레이션

Phase 2는 문제가 생겼을 때 해결책으로만 추가한다.

패키지가 늘면 관리 부담과 빌드 시간도 같이 는다.

## 명령어

```bash
npm run storybook         # dev 서버 (6006)
npm run build-storybook   # 정적 빌드 → storybook-static/
npm test                  # Vitest 1회
npm run test:watch        # Vitest watch
```
