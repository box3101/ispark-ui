# 설치

Vue 3 프로젝트에 ispark-ui를 붙이는 최소 3단계. peer dependency를 별도로 설치하는 이유는 Vue·radix-vue·date 패키지를 컨슈머 측 버전에 맞추기 위함이다.

## 1. 패키지 설치

```bash
# 본 패키지
npm install @leechanyong/ispark-ui

# peer dependencies (이미 설치돼 있으면 생략 가능)
npm install vue radix-vue @internationalized/date
```

## 2. 글로벌 스타일 import

엔트리(보통 `main.ts`)에 한 줄. CSS 변수·리셋·아이콘 클래스가 한 번에 들어온다.

```ts
// main.ts
import { createApp } from 'vue'
import App from './App.vue'

import '@leechanyong/ispark-ui/style.css'  // ← 컨슈머 SCSS보다 먼저

createApp(App).mount('#app')
```

> **import 순서가 중요하다.** 컨슈머의 테마/override SCSS는 반드시 라이브러리 다음에 와야 specificity 동률에서 이긴다. 자세한 내용은 <a target="_top" href="/?path=/docs/get-started-theming--docs">Theming</a>에서.

## 3. 컴포넌트 사용

필요한 컴포넌트만 named import. 트리쉐이킹이 동작해서 안 쓰는 건 번들에 안 들어간다.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { UiButton, UiInput, openToast } from '@leechanyong/ispark-ui'

const email = ref('')

const onSubmit = () => {
  openToast({ message: '저장되었습니다.' })
}
</script>

<template>
  <UiInput v-model="email" placeholder="이메일" />
  <UiButton variant="primary" @click="onSubmit">저장</UiButton>
</template>
```

## TypeScript

`d.ts`가 패키지에 포함돼 있어 별도 설정 불필요. 컴포넌트 타입은 자동으로 추론되며, `SelectOption`·`TableColumn`·`DateRange` 등 데이터 타입도 named export로 제공한다.

```ts
import type { SelectOption, TableColumn, DateRange } from '@leechanyong/ispark-ui'
```

## 검증

설치가 끝났는지 확인하려면:

```bash
npm ls @leechanyong/ispark-ui
```

브라우저에서 `<UiButton>`이 오렌지 톤 primary 색으로 렌더되면 글로벌 스타일까지 정상 적용된 것.
