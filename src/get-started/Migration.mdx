# 마이그레이션 정책 · 구현 현황

`team_agent_front`에서 어떤 컴포넌트를 어떤 기준으로 떼어왔는지. 정책을 먼저 보고, 그 결과로서의 현황을 본다.

## 마이그레이션 정책

라이브러리는 적게, 강하게. 실제로 쓰이는 것만 옮긴다.

`team_agent_front` 사용 빈도 10회 이상만 마이그레이션 대상이다. 그 아래는 원본에 두고, 요청이 오면 다시 검토한다. 새로 추가할 때는:

1. 사용처 10곳 이상 확인
2. variant·size 정리 적용 (UiButton: 8→4, 6→3)
3. PR description에 사유 명시

측정 방법: `cd C:/team_agent_front && grep -r --include="*.vue" -l "<UiName\b" . | grep -v "/ui/" | wc -l`
