## 정책 외 추가 구현분

원본 사용 빈도는 낮거나 0이지만 실사용 요구로 라이브러리화한 컴포넌트.

- **Radix-vue 래퍼** · UiTooltip, UiDropdownMenu, UiDatePicker, UiDateRangePicker, UiAccordion
- **유틸리티 / 폼 보조** · UiPagination, UiTab, UiRadio
- **알림 인프라** · UiToast + `openToast()` composable

## 마이그레이션 정책

라이브러리는 적게, 강하게. 실제로 쓰이는 것만 옮긴다.

`team_agent_front` 사용 빈도 10회 이상만 마이그레이션 대상이다. 그 아래는 원본에 두고, 요청이 오면 다시 검토한다. 새로 추가할 때는:

1. 사용처 10곳 이상 확인
2. variant·size 정리 적용 (UiButton: 8→4, 6→3)
3. PR description에 사유 명시
