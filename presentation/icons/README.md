# Proposal icon language

Reusable ISPark presentation icons wrap the **existing UiIcon / Lucide source**. No AI-generated symbols or 3D assets are included.

- `hero`: prominent 72–88px concept symbol on a restrained circular surface.
- `diagram`: 48–64px system/process node symbol.
- `inline`: 20–32px labels, captions and factual detail.
- Match semantic icon names (database, users, shield-check, workflow); keep tones and stroke width consistent.
- Web Storybook uses `ProposalIcon.vue`. PowerPoint exporting SVGs requires separate integration and is NOT yet implemented.
- This library is not a reproduction of any company's proprietary assets.
